# Before_test1_dataStructure
My data structure teacher gives us some mini code project to work before doing exam. These projects conclude ArrayList and Node. 

Part one:
1. Getting a consecutive character.
   i.e. ['a' ,'a', 'a', 'b', 'b', 'c', 'c', 'c', 'a'] will give output "a3 b2 c3 a1"
2. Rotating (or shift) the character to left or right without changing the size of the array.
3. Finding a part from the array the longest (streak) of number

Part two:
United two nodes, and rearrange it in order

Part three:
building a music system, where we can add, skip, and remove musics in the playlist using Node.
